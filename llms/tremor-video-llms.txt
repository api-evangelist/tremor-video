# Tremor Video (Nexxen DSP)

> Tremor Video DSP is the demand-side platform originally built by Tremor Video / Tremor International; after the consolidation of Tremor Video DSP and Amobee it is now marketed as the Nexxen DSP, part of the unified Nexxen advertising stack (DSP, SSP, Ad Server, Data Platform). Its REST API manages programmatic and connected-TV advertising objects — advertisers, insertion orders, line items, packages and creatives — authenticated with OAuth2 client-credentials.

## APIs

- [Nexxen DSP API (Postman documentation)](https://www.postman.com/nexxen-api/nexxen/documentation/9md8q3a/nexxen-dsp-apis): REST API for advertisers, insertion orders, line items, packages and creatives. Base URL https://services.amobee.com/campaign/v3/api.

## Authentication

- OAuth2 client-credentials. POST client_id + client_secret to https://services.amobee.com/accounts/v1/api/token, then send the returned access_token as `Authorization: Bearer <token>`.
- [Authentication profile](authentication/tremor-video-authentication.yml)

## Conventions

- [API conventions](conventions/tremor-video-conventions.yml): URI-path versioning (campaign v3, accounts v1), JSON envelope with `data` / `response_code` / `msg_type` / `msg`, resource-id query filtering; no documented idempotency key.
- [Data model / ERD](data-model/tremor-video-data-model.yml): advertiser → insertion orders / packages → line items → creatives.
